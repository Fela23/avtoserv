## 2. Переменные окружения

### 2.1 .env.example

```bash
# === API ===
EXPO_PUBLIC_API_URL=https://dev-api.avtoserv.com
EXPO_PUBLIC_APP_ENV=development

# === Sentry (мониторинг ошибок) ===
EXPO_PUBLIC_SENTRY_DSN=

# === Push Notifications ===
EXPO_PUBLIC_FCM_KEY=

# === Certificate Pinning (опционально) ===
EXPO_PUBLIC_CERT_PINNING_ENABLED=false

# === Debug ===
EXPO_PUBLIC_DEBUG=true
```

## 4. Тестовые сценарии

### 4.1 Авторизация

| # | Сценарий | Шаги | Ожидаемый результат |
|---|----------|------|---------------------|
| A1 | Успешный логин | 1. Открыть приложение 2. Ввести email/password 3. Нажать «Войти» | Редирект на HomeScreen |
| A2 | Неверный пароль | 1. Ввести неверный пароль 2. Нажать «Войти» | Toast: «Неверный email или пароль» |
| A3 | Refresh token flow | 1. Дождаться истечения accessToken (15 мин) 2. Выполнить действие | Автоматический refresh, продолжение |
| A4 | Refresh token expired | 1. Дождаться истечения refreshToken (7 дней) | Редирект на LoginScreen |
| A5 | Биометрический вход | 1. Войти с FaceID 2. Закрыть приложение 3. Открыть заново | Кнопка FaceID → вход |
| A6 | Регистрация | 1. Нажать «Зарегистрироваться» 2. Заполнить форму 3. Отправить | Редирект на HomeScreen |
| A7 | Восстановление пароля | 1. Нажать «Забыли пароль?» 2. Ввести email 3. Отправить | Toast: «Письмо отправлено» |

### 4.2 Автомобили

| # | Сценарий | Шаги | Ожидаемый результат |
|---|----------|------|---------------------|
| C1 | Список авто | 1. Открыть HomeScreen 2. Нажать «Мои авто» | Список карточек |
| C2 | Добавление авто | 1. Нажать «+ Добавить» 2. Заполнить форму 3. Сохранить | Новая карточка в списке |
| C3 | VIN Scanner | 1. Нажать иконку камеры 2. Направить на VIN | Автозаполнение поля VIN |
| C4 | Удаление авто | 1. Нажать «Удалить» 2. Подтвердить |汽车 удалено из списка |
| C5 | Удаление с активными записями | 1. Попытаться удалить авто с записями | Toast: «Невозможно удалить» |

|---|----------|------|---------------------|

### 4.9 Manual Upload (добавление внешних записей)

| # | Сценарий | Шаги | Ожидаемый результат |
|---|----------|------|---------------------|
| H1 | Добавление записи вручную | 1. Открыть историю авто 2. Нажать «+ Добавить запись» 3. Заполнить форму (дата, поставщик, услуга, цена, пробег) 4. Отправить | Запись в статусе «pending_review», отображается в истории |
| H2 | Добавление с файлами | 1. Заполнить форму 2. Прикрепить фото/документ (до 5 файлов) 3. Отправить | Файлы загружены, запись создана |
| H3 | Валидация формы | 1. Оставить обязательные поля пустыми 2. Нажать «Отправить» | Подсветка ошибок, отправка заблокирована |
| H4 | Offline добавление | 1. Выключить сеть 2. Заполнить форму 3. Нажать «Отправить» 4. Включить сеть | Запись синхронизирована после восстановления сети |

### 4.10 Consent Flow (152-ФЗ)

| # | Сценарий | Шаги | Ожидаемый результат |
|---|----------|------|---------------------|
| CF1 | Первый запуск | 1. Установить приложение 2. Запустить впервые | Модальное окно согласия на обработку ПДн |
| CF2 | Принятие согласия | 1. Нажать «Принять» в модальном окне | Согласие сохранено (MMKV), модалка закрыта, приложение продолжает работу |
| CF3 | Отклонение согласия | 1. Нажать «Отклонить» в модальном окне | Приложение закрывается или блокирует функционал (по ТЗ) |
| CF4 | Повторный запуск | 1. Закрыть приложение после принятия 2. Открыть заново | Модалка НЕ показывается (согласие уже сохранено) |
