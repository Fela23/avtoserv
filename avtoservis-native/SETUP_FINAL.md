### ❌ 2. ЧТО ТРЕБУЕТ ВАШИХ ДЕЙСТВИЙ (Не может быть сделано автоматически)

Следующие шаги требуют ручного вмешательства, так как касаются бинарных файлов и локальной среды разработки:

#### А. Файлы шрифтов (.ttf/.otf)
*   **Проблема**: Я не могу скачать или создать бинарные файлы шрифтов (например, `Roboto-Bold.ttf`). В коде они подключены, но физические файлы должны лежать в папке `assets/fonts`.
*   **Решение**: Вам нужно скачать их вручную (ссылки ниже) и положить в папку. Без них текст будет отображаться системным шрифтом, но приложение **не упадет**.
*   **Какие файлы нужны**:
    1.  `Roboto-Regular.ttf`
    2.  `Roboto-Medium.ttf`
    3.  `Roboto-Bold.ttf`
    4.  `Inter-Regular.ttf` (опционально, если используется в SPEC)
*   **Где скачать**: [Google Fonts - Roboto](https://fonts.google.com/specimen/Roboto) (нажмите "Download family").

#### Б. Логотипы и иконки приложений (.png/.svg)
*   **Проблема**: Я не могу генерировать графические файлы логотипа компании или иконку для магазина приложений.
*   **Решение**:
    *   В коде используются текстовые заглушки или векторные иконки из библиотеки `react-native-vector-icons` (они установятся через npm автоматически).
    *   Вам нужно будет заменить только главный логотип на экране входа (`assets/images/logo.png`) и иконку приложения в настройках сборки (позже, перед релизом).
*   **Что сделать сейчас**: Положите любой файл `logo.png` (например, 200x200px) в папку `assets/images`, чтобы увидеть картинку на экране входа.

#### В. Нативная сборка (Android/iOS)
*   **Проблема**: Чтобы получить `.apk` или запустить эмулятор, нужна компиляция на вашем компьютере с установленным **Android Studio** (для Android) или **Xcode** (для iOS).
*   **Решение**: Это физический процесс. Убедитесь, что у вас установлены:
    *   Java JDK 17
    *   Android SDK (через Android Studio)
    *   Эмулятор Android или подключенный телефон

## 🛠 ПОШАГОВАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ

Выполняйте команды последовательно в терминале.

### Шаг 1: Подготовка окружения
Убедитесь, что у вас установлены:
*   Node.js >= 18
*   React Native CLI: `npm install -g react-native-cli`
*   Android Studio (с настроенным эмулятором) ИЛИ Xcode

### Шаг 2: Установка зависимостей
Перейдите в папку проекта и установите пакеты:
```bash
cd /workspace/avtoservis-native
npm install
```
*(Это займет несколько минут)*

### Шаг 3: Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Откройте файл `.env` и проверьте адрес бэкенда:
```env
API_URL=http://ваш-ip-или-домен:5000/api
# Для тестов с локальным бэкендом используйте IP вашего компьютера, не localhost
```

### Шаг 4: Добавление ассетов (Шрифты и Лого)
1.  Создайте папки (если не созданы):
    ```bash
    mkdir -p assets/fonts
    mkdir -p assets/images
    ```
2.  **Шрифты**: Скачайте шрифты Roboto и поместите файлы `.ttf` в папку `assets/fonts`.
3.  **Логотип**: Поместите файл `logo.png` в папку `assets/images`.

> **Важно для iOS**: После добавления шрифтов нужно выполнить `cd ios && pod install`. Для Android шрифты подхватываются автоматически после пересборки.

### Шаг 5: Очистка кэша (Рекомендуется)
Перед первым запуском очистите кэш метры:
```bash
npm start -- --reset-cache
```
*(Оставьте этот терминал открытым)*

### Шаг 6: Запуск приложения

**Вариант А: Android**
Откройте **новый** терминал и запустите:
```bash
npm run android
```
*Команда соберет приложение и запустит его на активном эмуляторе или подключенном устройстве.*

**Вариант Б: iOS (только macOS)**
Откройте **новый** терминал и запустите:
```bash
npm run ios
```

## 🎯 ЧТО ДЕЛАТЬ ЕСЛИ...

| Проблема | Решение |
| :--- | :--- |
| **Ошибка "Command failed with exit code 1"** | Проверьте, установлен ли Java JDK 17 и настроена ли переменная среды `JAVA_HOME`. |
| **Метро не видит изменения** | Нажмите `r` в терминале с метро для перезагрузки, или `R` для жесткой перезагрузки. |
| **Белый экран при запуске** | Проверьте консоль эмулятора на наличие ошибок JS. Часто помогает `npm start -- --reset-cache`. |
| **Нет связи с бэкендом** | Убедитесь, что `API_URL` в `.env` указывает на правильный IP (не `localhost`, если проверяете с эмулятора Android, используйте `10.0.2.2` для эмулятора или реальный IP ПК). |
| **Шрифты не применились** | На Android: удалите приложение с эмулятора и установите заново (`npm run android`). На iOS: выполните `cd ios && pod install`. |
